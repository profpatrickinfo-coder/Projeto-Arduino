O projeto foi desenvolvido com o tema Arduino e Robótica, com o objetivo de apresentar um pouco sobre essa área da tecnologia e mostrar alguns projetos que podem ser feitos utilizando o Arduino. O site apresenta informações básicas, exemplos de projetos, como LED piscante, semáforo e robô desvia-obstáculos, além de um formulário para enviar ideias. Utilizei HTML, CSS e JavaScript para criar a página e também incluí um exemplo em PHP como diferencial. A ideia foi criar um site simples, organizado e fácil de navegar.
